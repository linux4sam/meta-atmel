# OpenEmbedded/Yocto Project Distro layer for Microchip's SoCs

## Description

The meta-mchp-distro layer consolidates common distro components and
metadata for Microchip platforms, streamlining development across various
Microchip devices for use with OpenEmbedded and/or Yocto Project.

## Layer Dependencies

This layer depends on the following layers:

```text
- openembedded-core
  - URI: git://git.openembedded.org/openembedded-core
  - Layers: meta
```

For information on the specific revisions used, refer to the
[meta-mchp manifest](https://github.com/linux4microchip/meta-mchp-manifest) repository.
